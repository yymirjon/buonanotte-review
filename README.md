# Buonanotte Review

A buildless HTML, CSS and JavaScript journal-style parody, plus a downloadable fictional research paper.

**Satire: all study data, participants, mechanisms, authorship and affiliations are fictional. Not peer reviewed or medical advice.**

Open `index.html` directly, or serve this folder with any static web server. No packages, analytics, cookies or external fonts are required.

## GitHub Pages

Publish the `main` branch, root directory, under repository Settings → Pages → Deploy from a branch. The website includes `paper.pdf` as a direct download.

The site intentionally requests search engines not to index the parody. The disclosure remains visible near the title and in the paper.
